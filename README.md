# FlyverFront

Le projet utilise Angular 19 et docker.

## Development server

Pour lancer le serveur de développement, exécutez la commande suivante :

```bash
docker compose up
```

Une fois le serveur lancé, l'application sera disponible sous l'URL : http://localhost:4200/.

## Commandes

Pour exécuter une commande dans le conteneur Docker, utilisez la commande suivante :

```bash
docker exec -it flyverfront_dev sh
```
## Stack Technique

- Angular 19
- Docker
- Tailwind CSS V4
- SpartanUI
